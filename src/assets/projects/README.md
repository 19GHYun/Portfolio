# 프로젝트 이미지 폴더

여기에 이미지를 넣기만 하면 해당 프로젝트 상세 페이지에 자동으로 표시됩니다.
`projects.ts`는 고치지 않아도 됩니다.

## 넣는 방법

프로젝트 **id** 이름의 폴더 안에 이미지를 넣습니다.
id는 `src/data/projects.ts`에서 확인할 수 있고, 주소창의 `/project/13` 숫자와 같습니다.

```
src/assets/projects/
  12/    <- RF 신호 분석 도구 3종
  13/    <- 동방마작전
```

## 파일 이름이 곧 설명

파일 이름이 이미지 아래(옆)에 설명으로 표시됩니다.
앞에 붙인 숫자는 순서를 정하는 용도이고, 설명에서는 지워집니다.

```
13/01-마작 테이블 렌더링.png     ->  1번째,  설명: "마작 테이블 렌더링"
13/02-패 선택 UI.png             ->  2번째,  설명: "패 선택 UI"
12/01-IntraPulse 분석 화면.png   ->  1번째,  설명: "IntraPulse 분석 화면"
```

숫자를 안 붙여도 됩니다. 그때는 파일 이름 순서대로 나옵니다.

## 지원 형식

`png` `jpg` `jpeg` `gif` `webp` `svg`

## 참고

- 이미지를 새로 넣으면 개발 서버가 자동으로 다시 읽습니다.
- 클릭하면 원본 크기로 크게 볼 수 있습니다. (방향키로 이동, ESC로 닫기)
- 새 프로젝트를 추가할 때도 그 id로 폴더를 만들면 똑같이 동작합니다.
